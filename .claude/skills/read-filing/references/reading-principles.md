# 财报阅读原则

本文件保存`read-filing`的长期信念层。执行任何子agent前必须完整读取;具体操作步骤仍以主`SKILL.md`为准。

## 目录

1. 排除优先
2. 阅读顺序与证据层级
3. 三表联动与归母口径
4. 附注、纵横比较与引用
5. 所有者利润与承诺兑现
6. 财报形态初筛

## 1. 排除优先

### 1.1财报用于排除,不是用于寻找买入理由

- 默认追问盈利是否真实、是否可持续、管理层是否诚信。
- 先识别应排除对象,再把深度研究资源用于少数剩余公司。
- 只复述“龙头、领先、成长”而没有质疑项,视为阅读失败。

### 1.2拒绝防御式空话

- “品牌强、护城河宽、持续优化、高质量发展”等词本身没有证据价值。
- 每个定性形容词必须紧跟具体事件、数字、日期、产品、客户或竞品。
- 管理层空话只记录“管理层如此表述”,不得转写为研究结论。

## 2. 阅读顺序与证据层级

### 2.1先财务报告和附注,后管理层讨论

固定顺序为:重要提示→审计意见→财务摘要→三大表→附注→管理层讨论。管理层讨论只用于校核已由报表和附注建立的事实,不能直接当作事实来源。

### 2.2附注高于正文汇总数

货币资金、应收、预付、其他应收、存货、在建工程、商誉、合同负债、应付、长投和有息负债必须拆到附注明细。必读12项及阈值见`statement-reading.md`第3节。

### 2.3每个数字都可回溯

- 年报数字写`(YYYY年报 p.N)`或更精确的节次与页码。
- 公告写日期、标题及官方URL。
- 找不到原始出处时写`待补充`,不得用记忆、搜索摘要或分析师观点补位。

## 3. 三表联动与归母口径

### 3.1权责发生制数字必须接受现金验证

利润表不能单独阅读。营收、净利和毛利率必须同时对照CFO/归母净利润、销售收现、应收、存货和合同负债;非经常损益必须从估值利润中剔除。

### 3.2默认使用合并报表和归母口径

- 合并报表反映上市公司与子公司的整体经营;母公司报表只用于校验。
- 归母净利润=合并净利润−少数股东损益。
- 归母净资产=合并净资产−少数股东权益。
- PE和PB分别使用归母净利润和归母净资产,不得混用少数股东权益与少数股东损益。

## 4. 附注、纵横比较与引用

### 4.1纵向5年与横向3家必须成对

- 每个关键指标同时报告本公司YoY/CAGR和同业务模式同业位置。
- 跨年变动超过±20%必须给出附注证据和解释。
- 同业应优先选公司在招股书或年报竞争格局中确认的可比公司,不能只按市值选择。

### 4.2勾稽优先于单点好坏

毛利率、负债率、流动比率或应收占比都不能脱离行业模式和现金流单独判定。机械阈值只产生初筛事实,最终风险结论交给`financial-redflag-scan`。

## 5. 所有者利润与承诺兑现

### 5.1所有者利润不是报表净利润

所有者利润≈CFO−维持性CapEx。维持性CapEx未直接披露时:

- 资产结构稳定的成熟公司可用折旧摊销乘通胀系数近似。
- 有产能明细时拆分新增产能和替换投入。
- 必须结合资产更新周期、维修支出、产能变化和折旧政策。不能仅凭CFO与总CapEx大小推断维持性CapEx低于折旧。

扩张性CapEx不能全部当作维持性投入;重资产或周期公司长期CFO无法覆盖全部CapEx时,需标记资本消耗风险。

### 5.2承诺需要跨5-10年验证

回读前5年展望,逐年并列目标、实际结果、目标是否消失及管理层是否解释。`read-filing`只提取带页码事实;诚信与画饼判定交给`management-analysis`。

## 6. 财报形态初筛

每个数字只标记更接近护城河型、周期型或混合型,不得直接推出投资结论:

| 指标 | 护城河型常见形态 | 周期型常见形态 |
|---|---|---|
| 毛利率 | 长期高且稳定 | 较低并随周期波动 |
| 累计CapEx/净利润 | 较低 | 较高 |
| 应收/营收 | 低于可比同业 | 高于同业或靠放账增长 |
| 偿债能力 | 少数年份利润可覆盖长期债 | 需要较长盈利周期偿还 |
| ROE | 长期稳定 | 波动大或出现负值 |
| 库存周转 | 与营收节奏匹配 | 库存增速明显快于营收 |

反直觉约束:

- 流动比率低不必然危险,应结合经营现金流与供应链占款能力。
- 负债低不必然优质,应结合资本回报和盈利稳定性。
- 应收高不必然销售差,关键是相对同业务模式同业及账龄、客户结构。

阅读笔记末尾写“财报形态初筛:护城河型/周期型/混合型,不构成投资结论”,并列3-5条证据。
