# 产品设计、生产与服务流程参考

本文件用于Step 2和Step 3。先选一条主流程，再按实际业务追加一条次级流程。不要把所有行业问题都塞进同一报告。

## 1.共同流程表

每个关键步骤使用同一字段：

|字段|要回答的问题|
|---|---|
|步骤与边界|从什么状态开始，到什么可验证输出结束？|
|输入与输出|材料、数据、人员、设计、库存或客户状态如何变化？|
|责任主体|公司、供应商、代工厂、渠道、加盟商或客户由谁控制？|
|周期|等待、加工、测试、运输或服务各占多久？|
|成本驱动|材料、人工、折旧、算力、租金、物流、获客或返工由什么决定？|
|能力指标|产能、良率、利用率、吞吐量、准时率、响应时间或人员利用率是多少？|
|质量控制|在哪个节点发现错误，漏检的经济代价是什么？|
|瓶颈|扩张时最先受限的是设计、设备、原料、人才、渠道还是客户需求？|
|财报落点|对应存货、固定资产、资本开支、研发、毛利、费用、应收或合同负债中的哪一项？|
|证据等级|按主skill的`高/中/低/需人工`记录。|

流程图必须从客户需求或产品定义开始，以客户收到价值、售后及反馈回流结束。

## 2.制造业与耐用品

推荐流程：

```text
需求洞察→产品定义→研发设计→BOM与供应商→样品和试制→工艺与设备→量产→质检→仓储物流→渠道或客户验收→售后→设计反馈
```

重点追问：

- 产品定义由品牌商、整机厂还是客户主导？规格变化的成本由谁承担？
- 研发输出是图纸、配方、模具、软件、工艺参数还是认证？
- 核心零件是否单一来源？供应商切换需要重新验证多久？
- 样品到量产经历几轮，量产良率爬坡需要多久？
- 瓶颈设备、模具、洁净环境、熟练工或认证能否快速复制？
- 理论产能、有效产能和可销售良品产能是否被混用？
- 质量事故由报废、返工、质保、召回还是客户罚款承担？
- 扩产资本开支转化为收入需要多久？闲置产能如何压低毛利？
- 外包制造时，公司是否仍控制设计冻结、供应商准入、排产、工艺、质量和交付？

财报映射：

- 原材料、在产品、产成品结构和库龄。
- 固定资产、在建工程、资本开支和折旧。
- 研发费用与资本化开发支出。
- 预付款、应付账款、合同负债和客户集中度。
- 毛利率、存货周转、应收周转和经营现金流。

### 2.1食品饮料和需要时间转化的产品

在通用制造流程外增加：

```text
原料选择→前处理→发酵或加工→分级→陈化或储存→勾调或配方→包装→渠道库存→终端消费
```

区分加工时间和等待时间。等待时间可能形成品质、库存、资金占用或供给稀缺，也可能只是低效。

白酒等产品至少查：

- 单批生产周期、基酒或半成品成熟周期。
- 投料产出率、分级比例和可售时间。
- 基酒、包装物和成品库存的口径。
- 设计产能、实际产量和可售量之间的时间差。
- 原料、人工、能源、折旧、包装和渠道费用。
- 批次一致性、食品安全和防伪控制。

不得因“年份久”直接认定稀缺。必须验证老化是否改善产品、库存是否可销售、渠道价格是否支持溢价。

### 2.2潮玩与IP衍生品

推荐流程：

```text
艺术家或IP获取→角色定位与产品企划→二维或三维设计→原型和材料选择→模具与样品→用户或内部评审→供应商报价和排产→量产与质检→包装物流→门店及线上发售→售后和销售反馈→补货或下一轮设计
```

重点追问：

- IP是永久自有、艺术家分成、固定授权还是外部影视授权？续约和最低保证如何影响利润？
- 角色定位如何转化为尺寸、材料、表情、配色、可动结构和包装设计？
- 从概念到原型、样品确认和正式上市各需要多久？谁拥有最终设计冻结权？
- 模具、最小起订量、材料、人工、授权费、包装和质检如何形成首批经济性？
- 第三方工厂如何准入？公司控制哪些材料、工艺、良率、验货、排产和交期？
- 新品命中率、首批售罄率、全价销售率、补货速度、退货率和库存周转如何反馈到下一轮设计？
- 热门IP跨手办、毛绒、饰品和生活用品扩展时，设计语言和质量能否保持一致？
- 限量发售是真实供给约束、市场测试，还是以稀缺营销掩盖需求不确定？

成本拆解至少列：

- 艺术家分成或授权费。
- 内部设计、原型和开发成本。
- 模具及首批摊销。
- 材料、代工、包装和质检。
- 仓储、跨境物流、关税和渠道履约。
- 折扣、退货、报废和库存减值。

公司未披露销量、平均售价、BOM、授权率或良率时，不得倒推出单件精确成本。第三方制造不等于没有生产能力，仍要分析供应商选择、设计冻结、质量控制、排产和全球补货。

## 3.软件与互联网

推荐流程：

```text
需求发现→产品设计→开发→测试→部署→获客或分发→激活→使用与服务→支持与安全→数据反馈→迭代
```

重点追问：

- 发布频率、缺陷率、故障恢复时间和安全事件。
- 自研、开源和云服务分别承担什么能力，迁移成本在哪里？
- 算力、带宽、内容、支付、客服和审核如何形成服务成本？
- 获客后能否激活、留存、付费和扩张，还是依赖持续买量？
- 数据反馈是否改善匹配、推荐、风控或产品设计；竞争者能否取得同类数据？
- 多产品之间是自然交叉使用，还是靠补贴和捆绑制造表面生态？

单位经济优先级：

- 单客户或单活跃用户收入。
- 服务或算力成本。
- 获客成本、回收期、留存和净收入留存。
- 内容、支付、渠道分成和客服成本。
- 研发投入与新增功能、可靠性或商业化之间的对应关系。

不得把零边际复制成本等同于零服务成本。

## 4.零售、平台和物流

推荐流程：

```text
供给组织或选品→定价与陈列→获客→下单或匹配→库存与履约→交付→退换与客服→复购→供给反馈
```

重点追问：

- 自营、联营、加盟、平台撮合或混合模式由谁拥有库存和承担损耗？
- 选品和供给密度是否降低客户搜索成本？
- 仓店网络、配送密度和订单密度如何改变单位履约成本？
- 佣金率、毛利率和履约费用率是否混用了总额与净额口径？
- 缺货、取消、准时率、退货率和投诉如何影响复购？
- 平台补贴退出后，供需双方是否仍留下？
- 渠道库存是否转移到经销商而没有消失？

财报映射：

- 同店销售、坪效、客单价、订单量和复购。
- 存货、减值、预付款、应付和合同负债。
- 履约费用、销售费用、租赁负债和门店资本开支。
- 平台总交易额与会计收入的口径差异。

## 5.专业服务和其他人力密集服务

推荐流程：

```text
线索与获客→需求诊断→方案和报价→人员或资源配置→交付→复核与质量控制→验收与回款→续约或转介绍→知识沉淀
```

重点追问：

- 谁负责获客，谁拥有客户关系？
- 高级人员、标准化流程、数据或品牌分别贡献多少？
- 报价按工时、项目、成果还是订阅，超支风险由谁承担？
- 人员利用率、项目周期、返工和流失率如何影响毛利？
- 质量依赖少数明星员工，还是可以通过流程、培训和工具复制？
- 收入确认、合同资产、应收和回款是否与交付进度一致？

单位经济优先使用单项目、单客户或单专业人员贡献，不用总收入除员工数掩盖职级和利用率差异。

## 6.受监管金融服务

推荐流程：

```text
客户识别→产品设计与定价→获客→准入或承保→资金配置或风险承担→持续服务与监控→理赔或催收→续期或退出→模型反馈
```

重点追问：

- 产品价值来自资金成本、风险筛选、便利、信任、网络还是交叉销售？
- 定价是否覆盖信用、市场、保险、流动性、合规和运营成本？
- 审批或承保速度是否以降低风控质量为代价？
- 渠道佣金、获客成本、续期率、赔付率、信用成本和资本占用如何形成单位经济？
- 监管资本和风险限额是否约束增长？

金融服务不用普通制造业毛利、存货和良率指标，改用风险调整后回报、资金成本、损失率、留存、服务成本和资本消耗。

## 7.成本估算纪律

估算顺序：

1. 优先使用公司直接披露的单位数据。
2. 使用分部收入、销量、成本和库存变动建立可复算桥。
3. 使用原料价格、工时、产能、折旧和渠道费用建立上下界。
4. 对无法分摊的总部、研发和品牌费用单列，不强行塞入单件成本。

标准表达：

```text
单位成本区间=[直接材料下界+人工下界+制造费用下界,
              直接材料上界+人工上界+制造费用上界]
```

必须同时给：

- 输入来源和期间。
- 数量、币种、含税与否及合并口径。
- 产量、销量或利用率假设。
- 对关键假设变化的敏感性。
- 与报表营业成本或毛利的残差。

残差无法解释时降低证据等级，不输出成本领先结论。
