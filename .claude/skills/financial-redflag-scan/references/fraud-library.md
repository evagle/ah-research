# Fraud Library — 财报造假识别与风险判定手册

本文件是 `financial-redflag-scan` skill 的深度操作参考, 专管 **"读到的数字是否触发风险/是否造假"**。阅读顺序/附注读法不在本文件管, 由 `read-filing/references/statement-reading.md` 覆盖。

**上游输入**: 本文件消费 `read-filing` 产出的事实笔记（附注12项原始金额/三表原始数据/关联交易明细）。没有事实笔记先跑 read-filing。

**下游hand-off**:本文件触发§1管理层道德风险→联动`management-analysis`skill;触发§2或§4结构性风险→建议value-profile主skill写Part 0`**估值阻断:**是—结构性风险`。

**阈值权威来源**:`thresholds.yaml`。本文件解释阈值的财务含义,不得另设同名指标的冲突数值。

## 1. 风险清单（10项快速信号）

以下10项用于快速扫描。第1-5项和第7项组成skill强制的6项高危附加检查;第6项已在29项清单覆盖;第8-10项属于解释层信号。预警只触发深查,不能单独作为造假定论。

1. **商誉/归母净资产≥20%为预警,>30%为高风险** — 预警档要求深查并购质量和减值假设;高风险档可能使一次减值显著侵蚀净资产
2. **其他应收款/流动资产≥10%** — 仅为预警和深查触发器;检查交易对手、关联关系、账龄、形成原因、资金流向和可收回性,不得单凭比例或关联方长年挂账认定股东占款。只有年报附注、审计结论、监管文书或资金流向等直接证据证明非经营性占用时,才升级为已证实占款
3. **在建工程≥3年不转固** — 要么工程失败,要么规避折旧
4. **经营现金流/归母净利润<50%连续2年** — 分母固定为归母净利润;利润真实性风险,可能是应收膨胀
5. **管理层道德风险**—正式财务造假或财务虚假陈述处罚/已证实关联交易构成股东利益输送或违规资金占用→直接大幅降级。仅有非正常定价但尚未证明损害方向或利益输送时先深查,不得一票否决。操纵市场或内幕交易由management-analysis专属诚信规则判断;非财务造假处罚不得直接升级,而是按底层事项独立阈值处理
6. **大存大贷** — 账上同时有巨额现金和有息负债且持续借款,属于高风险矛盾信号;需核查受限资金、利息收入和关联方占用,不能单凭该信号认定造假
7. **生物资产/农林渔牧** — 獐子岛式可走动/会飞的资产, 审计困难
8. **应收账款增速 > 营收增速 ≥ 20pp 连续2年** — 销售乏力, 靠放账填营收
9. **10y 累计 Capex / 10y 累计 NI > 50%** — 赚的钱一半以上必须花在维持/扩张固定资产上, 不是真赚钱生意, 护城河定性不超过 "窄" (与 moat-framework.md §3.5同一阈值)
10. **留存收益10y年化增速<8%,或出现下行**—逐年使用`期末留存收益=期初留存收益+本期归母净利润−分红±重述及权益转拨`复核;长期停滞或倒退是资本积累弱化信号,但需排除同一控制下合并、会计差错更正和权益内部转拨

**港股清单第6项替代**:港股没有"其他货币资金"科目时,从现金及银行结余、流动资产和受限资产附注逐项取得受限制银行存款、质押存款、保证金存款和非现金等价物定期存款,按经济实质去重。用受限或非现金等价物存款合计除以现金及银行结余和上述存款去重后的总额;占比>30%且无用途说明时为`是/预警`,未超过阈值或用途解释充分时为`否/无`,字段或口径缺失时为`需人工/待定`。报告必须列四类金额、合计占比、用途和页码。

**清单分母适用性**:清单第3项归母净资产≤0时不套存贷双高比例阈值,列货币资金、有息负债和负净资产绝对值并写`需人工/待定`;清单第20项归母净利润≤0时不运行在建年增/净利润分支,该分支写`不适用/无`并列绝对值,但生产资产/总资产分支仍独立判断。其余比例也必须先满足`thresholds.yaml`登记的分母适用性。

## 2. 三表勾稽公式（4条必查）

勾稽是造假识别的**核心技术手段**: 三张表之间的数字必须互相对得上, 任一条不过 → 标 `需人工`。

### 2.1应有销售收现勾稽
```
应有销售收现
≈ 营业收入 × (1 + 有效VAT税率)
 − Δ应收账款账面余额
 − Δ应收票据账面余额
 + Δ合同负债
 + Δ预收款项（IFRS 15/新收入准则前口径）
 − 本期核销
 ± 汇兑及外币折算影响
 ± 合并范围变动/合并处置影响
 ± 重分类调整
 − 本期票据贴现
 − 非现金抵账
 + 收回已核销坏账
```
以上调整项按应收款项、应收票据、合同负债和预收款项滚动表披露方向代入;汇兑、合并处置和重分类不得默认取0。有效VAT税率按各业务适用税率×对应含税前收入占比加权,税率取会计政策/税项附注;无法取得收入权重时只做披露税率范围敏感性并标`需人工`,不得猜值。

将结果与现金流量表"销售商品、提供劳务收到的现金"比较。背离率=`|实际值−应有值|/|应有值|`;背离超过`thresholds.yaml`规定的5%容差时,先在附注搜索票据背书转让,因为背书支付上游可能同时绕开经营现金流入和期末应收票据。仍无法解释才标`需人工`并质疑收入真实性。该式近似销售收现,不计算或证明收入真实性。

### 2.2销售收现
```
销售收现比 = 销售商品、提供劳务收到的现金 / [营业收入 × (1 + 有效VAT税率)]
```
健康参考值≥1.0。<1连续2年进入深查,但必须结合票据背书、非现金结算、合同负债变化和行业收款模式解释,不能直接判定造假。

### 2.3净利润→经营现金流桥
```
CFO=合并净利润
  +折旧摊销+减值损失+处置损失+财务费用−投资收益
  ±公允价值变动±递延所得税及其他非现金调整
  −Δ应收账款−Δ应收票据−Δ预付−Δ存货−Δ其他经营应收
  +Δ应付账款+Δ合同负债+Δ应付职工薪酬+Δ应交税费+Δ其他经营应付
```
以现金流量表附注的间接法调节表为准逐项映射,不得把未披露项目假定为0。合并净利润与合并经营现金流必须同口径;归母净利润只用于股东口径指标。走完全部项目后再计算残差。

### 2.4维持性 CapEx 近似
```
维持性 CapEx ≈ 折旧摊销 × (1 + 通胀系数)
自由现金流 ≈ CFO − 维持性 CapEx
```
通胀系数使用主要经营地官方报告期全年平均CPI同比;跨地区按收入权重加权,权重缺失时列敏感性区间并标`需人工`。
不能仅凭CFO与总CapEx大小推断维持性CapEx低于折旧;必须结合资产更新周期、产能变动、维修支出和折旧政策估算。

## 3. 造假识别的5个维度（高频作假手法库）

不特指哪家公司,列出高频作假手法。每家公司跑一遍以下5个维度,列"本公司是否沾边+页码或URL+证据";可量化项给金额和阈值,定性项给事件、主体、日期和文书依据。

- **收入端**: 关联方购销/突击发货/提前确认工程完工/放宽信用（填放账到应收）
- **成本端**: 在建工程停止转固（少折旧）/ 存货不跌价/研发资本化比例异常高
- **现金端**: 期末短暂借款补现金/受限资金混入非受限/理财产品分类为 "现金等价物"
- **利润端**: 卖资产/政府补助/公允价值变动/一次性所得税返还凑利润
- **结构端**: 频繁并购制造商誉 → 后续慢性减值/子公司并表时点选择/关联方剥离亏损业务

## 4. 造假模式叙述库（A1 / A2 / A3）

§1 / §3是**数字型**和**手法型**; 本节是**模式型** — 帮子 agent 理解**为什么**数字异常 = 真实造假信号。29项计分触发任一项, 且可对号入座到 A1/A2/A3, 在报告"发现的风险 summary" 段落明确引用并加注 "模式 A<N>"。

### A1客户塞货 (channel stuffing)
- **信号组合**: AR 增速 > 营收增速 ≥ 20pp **且** 存货增速 > 营收增速 ≥ 20pp **且** 应付账款 (AP) 增速趋缓/压缩
- **为什么**: 公司把货硬压给经销商, 确认营收; 经销商卖不动导致 AR 积压 + 自家存货同步膨胀; 同时供应商也知道销售疲软, 不再给信用期, AP 不增反降
- **典型场景**: 白酒/消费品渠道库存周期顶部; 集采前夕的医药公司

### A2库存减值掩盖 (inventory obsolescence hiding)
- **信号组合**: 存货周转天数翻倍以上 **且** 毛利率保持稳定 **且** 存货跌价计提/存货比值10年不升反降
- **为什么**: 存货占用资金翻倍 = 滞销; 正常情况毛利率应下降 (降价清库) 但却稳定 = 没做减值; 跌价计提比例反而走低 = 故意压缩减值以保利润
- **典型场景**: 周期股晚期 (钢铁/煤炭/猪); 电子/家电 technology refresh 前夕

### A3供应商融资压力 (vendor squeeze)
- **信号组合**: 应付账款天数 (AP days) 从正常60-90天被压缩到30-40天 **且** 营收加速 **且** 资产端现金仍在紧张
- **为什么**: 供应商担心公司经营不稳, 要求提前付款或缩短账期; 公司被迫动用现金流保供应链, 即便营收看起来在增长, 实际经营现金流承压
- **典型场景**: 高杠杆地产/扩张期互联网/大宗商品暴跌后的 commodity 公司; 也是破产前2-4季度的 early warning

**用法**:
- 上述3模式**不纳入29项计分**, 属于**深度解释层**。
- 主agent复核时:按清单ID去重后,至少3个不同的29项清单ID指向同一pattern A<N>时标**系统性造假高风险**。pattern只能解释已触发风险,不得单独升级为剔除;6项附加检查、三表勾稽、补充质检和造假维度中的重复事实不增加计数。

## 5. 书中补充质检信号

以下项目来自财报反欺诈章节,用于补足29项定量清单。它们先作为解释层逐项记录`异常/未见异常/不适用/需人工+严重度+证据与动作`,没有充分行业证据时不得自造统一硬阈值:

1. **员工薪酬合理性**:用应付职工薪酬附注的"本期增加"结合员工人数估算公司承担的人均薪酬,与历史和同业比较。异常低或异常高都需解释。
2. **销售配套费用勾稽**:比较运费、装卸费、出口业务海关费用与收入增速。收入大增而相关费用不增或反向变动时,检查是否存在虚构收入。
3. **其他经营活动收到的现金**:检查突然增加的金额、交易对手和性质,排除关联方资金或非经营性项目包装经营现金流。
4. **其他业务收入和偶发收益**:检查占比突然上升、主营与其他业务重复记录,以及多年反复出现的所谓一次性收益。
5. **长期待摊费用**:检查将日常修理费、营销费或其他当期费用资本化的可能,并关注余额和摊销年限异常。
6. **长期预付款**:检查预付账款账龄超过一年、关联方长期挂账或用途与主营业务不符。
7. **治理异常**:检查独立董事集体辞职、财务总监频繁更换和审计机构反复更换。
8. **交易对手真实性**:对突然出现的大客户或供应商检查合理商业用途、交易价格、地址、执照、年审和税务资料;记录客户或供应商注册信息异常。
