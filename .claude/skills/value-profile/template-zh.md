抽血渠道可能包括以下"合规抽血"形态——不是违规但对 small shareholder 是机会成本:
- **政策性任务**: 上市公司承担非经济效益的社会责任 (扶贫/就业/维稳/地方产业配套)
- **地方政府强制采购**: 要求使用特定本地供应商, 定价高于市场
- **税收/土地优惠 vs 反哺**: 看似给优惠, 实则要求配套投资/慈善捐赠
- **商标与品牌权属**: 母公司集团持有核心商标, 上市公司每年付使用费
- **集团销售公司分成**: 销售环节通过集团下属销售公司, 吃中间差价
- **公益与基建摊派**: 地方性基建/公益项目强制配套出资

**茅台案例** (启发本节设计): 贵州茅台的控股股东茅台集团 (贵州省国资委 100% 持股) 历年通过以下渠道低强度抽血:
1. 商标 "茅台" 归集团, 上市公司支付年度使用费
2. 集团销售公司分成非上市主体吃加价差
3. 地方性慈善/公益承诺 (支持贵州教育/扶贫/文化)
4. 省政府配套基建 (机场/水库/道路) 摊派投资

上述案例仅用于量化具有商业实质且定价公允的合法关联交易。监管文书、审计结论、法院裁判或闭合资金流已证实侵占、违规担保或非公允利益输送时,正式处罚按canonical状态映射为`已证实侵占/一票否决`,不得因金额较小或护城河较强降级。
