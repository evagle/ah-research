# Valuation — 本项目估值法与买卖决策参考

本文件定义**本项目估值法**: 公式、适用边界、买卖触发。运行 skill 的 Step 6时直接引用。

价格、十年期国债收益率和估值倍数都取AS_OF当日或之前最近交易日；跨币种每股价值使用同一规则取得汇率。完整市场比较绑定不可变`market-data manifest`；manifest至少保存市场数据日期≤AS_OF、价格官方响应SHA-256、无风险利率官方响应SHA-256、官方响应绝对路径和解析值，profile保存manifest绝对路径及文件SHA-256，不得混用当前值、AS_OF之后的数据或可变缓存。

合理市值和市场比较按输入依赖分开。当前价格只用于当前估值比较、买卖点触发和持仓姿态；缺少当前价格不得阻断合理市值。港股等跨币种标的另用已验证汇率换算每股价值；缺少汇率时仍输出财务报表币种的合理市值，只把当前价格比较和跨币种每股价值标为未完成。缺少某项输入不得删除不依赖它的计算结果，也不得把解析工具暂不支持某种原始格式写成市场数据不存在。

## 1. 核心公式

### 1.1合理估值
```
合理估值 = 3 年后归母净利 × min(1 / rf, 25PE) × (1 ± 10%)
```
- **rf**: 10年期国债收益率, 近年 ~3.5%, 对应 PE 锚 ~28x
- **上限25PE**: 即使 rf 极低, PE 也不超过25（避免长期利率假设崩溃）
- **±10%**: 合理估值区间而非单点

### 1.2买点
```
买点 = 合理估值 × 50%  (标准情形)
买点 = 合理估值 × 35%  (高杠杆)
买点 = 穿越周期合理估值 × 40%-50%  (周期股)
```
高杠杆定义:
- `最近3年平均经营现金流=3年CFO合计/3`;有息负债/最近3年平均经营现金流>3时判为高杠杆。
- 平均经营现金流≤0且有息负债>0时直接判为高杠杆,不得对非正分母套比例阈值。
- 净资产≤0且有息负债>0时直接判为高杠杆;净资产为正时,有息负债/净资产>1也判为高杠杆。
- 公用事业叠加高杠杆时,买点必须同时满足`股息率>无风险利率×1.3且市值≤DCF合理估值×35%`。

### 1.3卖点（双轨, 取较低者）

本节仅适用于PE法。银行PB法使用§3所列子类型PB上限和资产质量恶化条件;周期股、公用事业分别使用§3的周期与股息率退出条件。

```
卖点轨道 A = 合理估值 × 150%
卖点轨道 B = 当年净利 × 50PE
卖点 = min(A, B)
```
A 轨保护在极端乐观情境下的退出；B 轨保护在未来利润 significant slippage 后退出。

### 1.4 "股权债券"视角 (Equity Bond, §1.1的经济直觉)

PE 锚的背后是一个"把股票看成利息不固定的债券"的思维框架, 用来判定股价便宜贵时当参考心锚:

```
初始收益率 = 税前 EPS / 股价
```

- **摸索判断**: 初始收益率 > 长期国债利率 × 2 (e.g. 当前 rf ~3.5%, 对应阈值 ~7%) = 有吸引力候选
- **换算对照**: 初始收益率7% ⇔ PE ~14 (税前); 5% ⇔ PE ~20; 4% ⇔ PE ~25 (本项目上限)
- **护城河公司独有优势**: 息票 (EPS) 会随时间增长, 不像真债券利息固定; 持有10年的真实年化收益 = 初始收益率 + 复合增长率

**何时用**: §2三档 NI 测算做完后, 用 Equity Bond 视角做一次 **心算交叉检验** —— 若中性档3y NI 对应初始收益率明显低于长期国债 ×1.5, 说明当前合理估值 / PE 锚**太乐观**, 应 reconsider 是否把 PE 锚从25降到20或更低。

**不替代 §1.1公式**: 这是一把心锚/直觉工具, 不替代 `合理估值 = 3y NI × PE 锚` 主公式; 两者得出的合理价差异 > 30% 时, 取较保守者, 并在 profile 里注明理由。

## 2. 三年后净利润预估

### 2.1必填三档
乐观/中性/悲观, 至少2个业务板块拆解。每档结构:
```
业务板块 i 营收_t+3 = 量_t+3 × 价_t+3
业务板块 i 净利润_t+3 = 营收_t+3 × 净利率_t+3
净利润_t+3 = Σ 业务板块 i 净利润_t+3
```

### 2.2三大来源
1. **管理层指引** (优先, 若存在): 年报董事会报告、业绩说明会、投资者交流会的量化预期
2. **行业天花板 + 份额**: 行业总量天花板 × 目标份额 × 行业净利率
3. **产品线外推**: 现有产品线的 CAGR 假设, 新品/新市场/并购独立估

### 2.3每档必附 "具体假设一句"
不接受 "我们认为未来3年会增长"。必须:
```
悲观: 主营产品 A 价稳定, 量年化 +2%, 净利率降至 30% → 归母净利 XXX 亿
中性: 产品 A 提价 3%/年, 量年化 +5%, 净利率 33% → XXX 亿
乐观: 提价 5%/年, 量年化 +8%, 新产品 B 贡献 5 亿利润, 净利率 35% → XXX 亿
```

## 3. 6类生意估值矩阵

对每家公司先归类, 再套对应的估值方法。**同时符合多类 → 取最严档**。

| 生意类型 | 估值方法 | 买点 (合理估值 ×) | 卖点 | 关键约束 |
|---|---|---|---|---|
| **强护城河消费/互联网龙头** | PE 锚 = min(1/rf, 25), × (1 ± 10%) | 50% | min(150%, 50PE) | 三大前提必过; 护城河宽/中 |
| **周期股** | 穿越周期平均利润×成本档倍数;波峰调整系数固定为0.75 | 40%-50%;叠加高杠杆时35% | 繁荣期PE到10即减仓 | 低成本15PE;中位成本10-12PE;高成本不估值 |
| **高成长股（年化 > 25%）** | 25PE 上限不破 | 50% | 50PE 必减 | 不用 PEG 抬到40+; 保守下限; 反向需3年窗口 |
| **金融—银行** | 按银行子类型使用0.6-1.3PB×真实净资产 | 35% | 市值/真实净资产超过所选子类型PB上限,或资产质量显著恶化时退出 | 具体锚和子类型上限以`industry-overlays.md`§2.4为唯一来源 |
| **金融 — 保险** | 默认回避 | — | — | EV 折现假设多且无法客观验证 |
| **高杠杆 (地产/部分电力)** | PE 下调到8-12 | 35% | PE > 15减仓 | 硬指标: 有息负债/净资产 > 1 |
| **公用事业 (水电/高速/港口)** | 稳态 FCF / (rf + 2%) | 股息率 > rf × 1.3 | 股息率 < rf 退出 | 看折旧 vs 维持性 CapEx 差额 |

### 3.1“不适用单年PE”/“默认回避”
- 周期股“不适用单年PE”只禁止用当前或单年净利润,仍按完整周期平均利润和成本档倍数估值
- 保险/创新药/生物资产重等默认回避类型→Step 6不输出估值数字,Part 0标“定性研究only”

### 3.2分档不确定时
- 多类叠加按主路线优先级选择唯一估值基础;高杠杆+周期仍用穿越周期平均利润,高杠杆叠加时35%优先于40%-50%,不得改用单年8-12PE
- 护城河窄→仅在其他gate全部通过时把PE上限从25降到20;护城河弱/否→不输出估值数字

## 4. 适用性边界

本节边界仅适用于PE法。PE锚估值法**不适用**于:
- 当年或下年净利润为负的公司（无 PE 可算）
- 净利润构成中非经常性损益 > 30%（E.g. 卖子公司/政府补贴大）
- 资本结构剧变期（e.g. 刚 IPO 或刚重大并购）
- 会计准则切换当年（金融资产重分类/租赁准则切换/收入准则切换）

这些情况只阻断PE法。若周期公司的当前利润为负,但完整周期平均净利润为正且成本档证据完整,当前亏损不阻断周期法;银行PB法和公用事业DCF法也按各自适用性继续。没有可靠替代路线时,Step 6才只输出定性判断,不给数字。

## 5. 持仓姿态三态 + 分批规则

### 5.1三态
- **低于买点**: 分批建仓, 3-5批, 每批间隔5-10% 降幅触发
- **买点到卖点之间**: 持有, 不加不减（"价格不是信息" — 详见 discipline.md）
- **高于卖点**: 分批减仓, 3-5批, 每批间隔10-15% 升幅触发

### 5.2分批操作
- 单次不超过总仓位的20%
- 连续3次同方向操作后暂停1个月, 避免情绪化操作
- 首次建仓不超过组合5%,验证2个季度后才允许加到目标权重

## 6. 估值动摇的处理

估值判断在研究过程中 "微调" 是正常的, 但若:
- 3年后净利润中性档需要下调 > 20%
- PE 锚需要从25降到15
- 三大前提从 "过" 变 "不过"

这叫 **估值动摇**, 不是微调。动摇发生时:
1. 停止买入/继续 buy（即使价格已跌到原买点之下也不买）
2. 重走 §1 / §3 / §5, 重新判定三大前提
3. 若重判后估值结论改变 → 更新买点卖点, 继续
4. 若重判后发现当初判断错了 → 认错, 按新估值决策（可能是清仓）

详见 `discipline.md`。

## 7. 全稀释股本调整

计算归母净利时:
- **加** 可转债若全部转股后的股本稀释
- **加** 管理层已授予未行权的期权/激励股
- **不加** 股份回购（已回购库存股应从总股本中扣除）

3年后的每股收益应按全稀释股本计算, 避免 "表面 EPS 高, 实际稀释后一般" 的陷阱。

## 8. 估值表达（Step 6输出格式）

先按主估值路线五选一,只输出所选路线字段,不得输出未选路线字段:

- **PE法**:3年后归母净利润三档、PE锚、合理估值区间、50%买点、`min(合理估值×150%,当年净利×50PE)`卖点。
- **银行PB法**:真实净资产、银行子类型、所选PB区间、35%买点、超过所选子类型PB上限或资产质量显著恶化的卖点。
- **周期法**:完整周期平均利润、成本曲线位置、成本档倍数（低成本15PE;中位成本10-12PE;高成本不估值）、穿越周期合理估值、40%-50%买点;AS_OF处于可验证波峰时,波峰调整系数固定为0.75并乘在成本档合理估值上;叠加高杠杆时改用35%买点,繁荣期PE≤10退出。
- **公用事业DCF法**:稳态自由现金流、折现率、合理估值区间、股息率>无风险利率×1.3的买点、股息率<无风险利率的卖点。
- **高杠杆法**:3年后归母净利润三档、8-12PE锚、合理估值区间、35%买点、PE>15的卖点;不使用PE法双轨卖点。

五条路线都补当前股价/市值、姿态、置信度和低置信度原因。保险或定性研究only不输出估值、买点或卖点。
