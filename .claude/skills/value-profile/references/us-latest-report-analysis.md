# US Latest-Report Analysis

## Independent analysis

按以下顺序完成，任何后序来源不得反向改写前序原始事实：latest 10-Q/10-K、latest audited 10-K、prior four comparable quarters、same-cycle SEC-filed 8-K earnings exhibits、issuer IR、独立行业/同业/market evidence。

### KPI Tree

| Layer | Required metrics and questions |
|---|---|
| Demand scale | Nights and Seats Booked、Gross Booking Value、ADR、reported/FX-neutral growth及可比two-year CAGR |
| Monetization | Revenue、implied take rate、收入增速相对预订增速 |
| Network and expansion | Supply、quality actions、priority countries、less-mature markets及新业务adoption |
| Profit quality | GAAP operating income、net income、Adjusted EBITDA、operating cash flow、free cash flow、margin和cash conversion |
| Reinvestment | Product/new-business spend、capex、stock-based compensation和launch milestones |
| Capital allocation | Cash/investments、debt、repurchases、diluted share count和dilution offset |
| Expectations | Actual versus prior guidance，分别列FX、tax及one-time effects |

每个适用metric显示current quarter、YoY、YTD、TTM、two-year CAGR和prior guidance/actual。未披露就写missing，不推造listing count、repeat rate、market share或new-business revenue。

### Strategy-to-Value Chain

固定列为`Strategic action | Execution evidence | KPI change | Financial transmission | Long-term value implication | Market-recognition evidence | Evidence grade`。Airbnb至少检验core marketplace quality/price transparency、international expansion、host tools/co-hosting、Experiences and Services、app/AI investment、marketing efficiency/direct traffic及capital allocation。

Market-recognition evidence必须与公司行动分开。没有直接归因时只写`supported possible re-rating factor`，结论证据最多为Medium；不得把股价同步变化写成因果证明。

每个材料结论显式标`High`、`Medium`、`Low`或`Manual review`：SEC/可复核issuer事实可为High，High输入的透明计算可为Medium，间接或陈旧证据为Low，身份/口径/数值冲突为Manual review。

## Prior-analysis cross-validation

只在Independent analysis及初稿结论完成后读取用户既有分析。逐项标`confirmed | updated | contradicted | unresolved | out of scope`，实质结论引用当前SEC或当前外部证据；既有文档只能补问题和检验thesis drift，不能填补证据行或提高证据等级。
