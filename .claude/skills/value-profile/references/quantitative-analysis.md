# 定量分析方法

本文件是 `value-profile` Part 2（§Q1-§Q12）的推荐方法。进入 Step 4
前完整读取。它规定数据窗口、计算口径、行业适配、输出结构和完成
检查；具体风险阈值仍以 `financial-redflag-scan` 为准。

取数优先使用AKShare＋官方AKTools，具体接口、参数、分页及本地备用调用见[共享取数指南](../../source-discovery/references/akshare-aktools.md)。一次获取报表后在本地筛选可比年度并计算指标；用于经审计结论的原值仍核对并绑定选中年报，第三方指标不自动获得高证据等级。

## 1. 使用原则

### 1.1 推荐规范，不是填表任务

以下表格是推荐规范，不是跨行业硬性清单。存在10个可比完整财年时展示全部10年；
上市历史不足、披露口径变化、行业不适用或数据不可比时，可
缩短、替换或省略指标，并在表下注明原因和证据等级。不得为填满10年而
猜数，也不得用不相干的代理指标伪造连续序列。
简言之：不得为填满10年而猜数。

先回答公司最重要的财务问题，再用 §Q1-§Q11 查漏。表格必须服务于判断：
同一组数字如果不能说明盈利、增长、资本消耗、财务安全或股东回报中的
至少一项，不进入正文。

### 1.2 财务骨架与行业指标并存

非金融公司默认保留一组可跨公司比较的财务骨架：收入、归母净利润、
合并净利润、经营现金流、资本开支、研发、总资产、归母权益、现金、
有息负债和股数。行业 overlay 替换经济意义不足的指标，并增加真正驱动
业务的运营指标；不能因为有行业指标就删除全部基础财务数据。

### 1.3 不使用统一“优秀线”替代分析

ROE、毛利率、流动比率和资本开支比例没有跨行业通用的优秀阈值。比较
顺序为：公司历史、同一商业模式的同行、资本成本或监管要求。经验阈值
只能作筛查提示，不能直接产出“优秀/危险”结论。

## 2. 数据窗口与可比性

1. 以 `AS_OF` 前已披露的最新完整财年为终点，优先取最近10个完整财年。
2. 公司提供重列比较数时，使用最新年报中的重列值；只有差异足以改变
   趋势或判断时，才在正文说明原值与重列值。
3. 会计准则、分部划分、收入确认或指标定义变化时，在序列中设置断点。
   不跨断点计算 CAGR、均值或趋势，除非公司提供可比重列。
4. 年度表使用完整财年。季度、上半年和 YTD 单独列示，不年化后混入年度
   序列。
5. 金额统一到一种币种和单位；换算值必须保存汇率、日期和公式。公司原始
   报表本币数据优先于换算数据。
6. `Avg` 默认是窗口内可比年度的简单算术平均；累计值、期初至期末 CAGR
   和中位数必须分别命名，不能都写成“平均”。

## 3. 三层数据结构

### 3.1 报表原值层

保存公司披露的原值、币种、单位、财年、报表或附注名称、页码、是否重列
及会计口径。IFRS/中国会计准则数据与公司定义的非国际财务报告准则指标
分开保存。

### 3.2 计算指标层

每个计算值保存公式、分子、分母、平均余额取法和分母异常状态。分母为
零或负数而指标失去经济意义时写 `N/M—分母非正`，不得输出误导性百分比。
缺少原值写 `N/A—未披露`；业务不适用写 `N/A—不适用`。两者不能混用。

### 3.3 分析结论层

每个 §Q 只保留 1-3 个重要结论，按“趋势→原因→影响”写：

- **趋势：** 数字发生了什么，覆盖什么期间。
- **原因：** 用业务结构、价格/数量、费用、资本投入或会计口径解释。
- **影响：** 对未来利润质量、资本回报、财务安全或估值意味着什么。

每项结论标 `证据等级：高/中/低`。审计报表直接值及可复算比率通常为高；
公司定义且有完整对账的指标为中高；口径明确的第三方行业估计为中；仅有
代理变量或口径断点时为低。证据等级评价证据，不评价结果好坏。

## 4. 通用指标定义

除公司另有清晰定义外，使用以下口径。表头或脚注必须说明分母采用合并
净利润还是归母净利润，不得只写“净利润”。

### 4.1 回报与盈利

- `ROE = 归母净利润 / 平均归母普通股股东权益`
- `ROA = 合并净利润 / 平均总资产`
- `投入资本 = 归母权益 + 少数股东权益 + 有息负债 - 非经营现金`
- `ROIC = 税后经营利润 / 平均投入资本`
- `毛利率 = 毛利 / 收入`
- `营业利润率 = 营业利润 / 收入`
- `归母净利率 = 归母净利润 / 收入`

平均余额优先使用年初、年末算术平均。并购、分拆或大额回购使年末余额
失真时，使用季度平均或明确写出限制。

“核心利润”不是法定报表项目。只有在调整项目逐项可追溯时才使用，并
提供从报表营业利润或净利润到核心经营利润的完整对账。不得机械套用
“毛利减三费”而忽略研发、减值、股份支付或收入分成等真实经营成本。

### 4.2 留存利润检验

当分红、回购和归母利润可取得且股本结构可比时，可补充：

- `累计留存利润 = 累计归母净利润 - 累计现金股息 - 净回购注销`
- `留存利润回报 = 期末归母净利润增量 / 前期累计留存利润`

净回购注销只包括实际注销或减少普通股权益的净额；为股份支付回购但未
注销的库存股单列。该指标受周期和并购影响，只看至少5年，不作单年判断。

### 4.3 盈利质量与资本消耗

- `现金含量 = 经营现金流 / 合并净利润`
- `经营现金流率 = 经营现金流 / 收入`
- `资本开支利润比 = 现金资本开支 / 合并净利润`
- `资本开支现金流比 = 现金资本开支 / 经营现金流`
- `基础自由现金流 = 经营现金流 - 现金资本开支`
- `研发强度 = 当期研发开支 / 收入`
- `股份支付强度 = 股份支付费用 / 收入`

公司披露的“资本开支”可能是资产新增额，不等于现金流量表付款。两种口径
可以并列，但必须分别命名，不能拼成一条十年序列。维持性资本开支只有在
假设和敏感性明确时估算，不冒充报表值。

### 4.4 成长

- `同比增速 = 本年值 / 上年可比值 - 1`
- `CAGR = (期末值 / 期初值)^(1 / 间隔年数) - 1`

收入、经营利润、归母净利润、经营现金流、每股收益和归母权益分别计算；
负值跨正值时不计算 CAGR。增长必须拆分到主要业务或量、价、成本，不能
只给集团合计。

### 4.5 运营效率

- `总资产周转率 = 收入 / 平均总资产`
- `应收天数 = 平均贸易应收款 / 收入 × 365`
- `存货天数 = 平均存货 / 销售成本 × 365`
- `应付天数 = 平均贸易应付款 / 销售成本 × 365`
- `现金周转周期 = 存货天数 + 应收天数 - 应付天数`

只使用贸易性项目。其他应收、金融资产、递延收入和预收款不混入贸易应收
或贸易应付。平台、银行和轻资产互联网公司若周转天数不能解释经营效率，
按行业 overlay 改用人效、用户、交易或单位经济指标。

### 4.6 偿债与流动性

- `有息负债率 = 有息负债 / 总资产`
- `净现金 = 可自由支配现金及短期投资 - 有息负债`
- `现金覆盖率 = 可自由支配现金及高流动金融资产 / 有息负债`
- `流动比率 = 流动资产 / 流动负债`
- `速动比率 = (流动资产 - 存货 - 其他难变现流动资产) / 流动负债`
- `利息保障倍数 = 息税前利润 / 利息费用`

受限现金不计入可自由支配现金。公司口径净现金只有在构成完整披露时使用，
并与计算口径并列核对。

### 4.7 资产负债表与利润表

资产按经济作用分为现金、经营性营运资产、生产资产、投资资产、商誉及
其他；负债分为经营性无息负债、有息负债和其他。每类同时列金额和占总
资产比例，避免大公司绝对额掩盖结构变化。

百分比利润表以收入为 100%，至少覆盖毛利、销售及营销、管理、研发、
股份支付、营业利润、投资与公允价值损益、联营/合营收益、税前利润、税项
和归母净利润。科目列报变化时只展示可比项目。

## 5. A股与港股适配

### 5.1 销售收现

A股只有在现金流量表披露“销售商品、提供劳务收到的现金”时才计算销售
收现率，并按适用增值税和滚动项目解释。港股通常不披露该毛额项目，不
计算或反推；改用应收账款、合同负债和经营现金流与收入的变化判断回款。

### 5.2 调整后利润

A股使用法定披露的扣非净利润（扣除非经常性损益后归母净利润）。港股不
自行构造“扣非净利润”；只有公司披露并提供对账的非国际财务报告准则盈利时才列示，
同时保留 IFRS 起点、每项调整及调整后结果。没有完整对账就直接分析投资
收益、公允价值、减值、处置和税务项目。
不得自行构造港股扣非净利润。

### 5.3 科目和定义

按经济实质映射 HKFRS/IFRS 科目，不要求港股使用 A 股科目名称。`deferred
revenue`、`contract liabilities`、`receipts in advance` 先核对定义再连接
序列。股份支付区分权益结算与现金结算；回购区分已注销、库存股及代股份
计划持有。

## 6. 行业适配

先读 `industry-overlays.md` 选择一个主 overlay。执行顺序：

1. 保留适用的基础财务骨架。
2. 用主 overlay 替换没有经济意义的通用指标。
3. 增加 3-8 个真正驱动业务的运营指标。
4. 次级 overlay 只补充不冲突的指标。
5. 公司未披露 DAU、ARPU、CAC、LTV、抽成率等指标时写 N/A，不用集团
   收入除以不匹配的用户数或交易额。

互联网平台至少区分主营经营利润、投资及公允价值影响、股份支付、研发和
资本开支；用户指标按产品分别列，不把微信月活当作腾讯集团收入的 ARPU
分母。银行、保险、地产、周期和公用事业直接使用各自专属 schema。

## 7. §Q1-§Q12 推荐结构

| Section | 推荐表格 | 必须回答的问题 |
|---|---|---|
| §Q1 | ROE、ROA、ROIC、归母权益；行业 overlay 的核心业务量 | 公司靠什么资产和资本赚钱 |
| §Q2 | 毛利率、营业利润率、归母净利率、主要业务利润率 | 利润池在哪里，趋势为何变化 |
| §Q3 | 现金含量、经营现金流率、资本开支、研发、股份支付、调整项目 | 报表利润有多少变成现金，需要多少再投入 |
| §Q4 | 收入、经营利润、归母净利润、经营现金流及分业务增速 | 增长由什么推动，是否持续 |
| §Q5 | 总资产、权益、负债、研发、资本开支和关键生产/投资资产 | 增长是否依赖资产和资本快速扩张 |
| §Q6 | 适用的周转天数或行业运营效率指标 | 经营效率改善还是恶化 |
| §Q7 | 现金、有息负债、净现金、流动性、利息覆盖 | 下行情景下是否需要外部融资 |
| §Q8 | 经营现金流、现金资本开支、自由现金流、股息、回购 | 现金最终用于再投资、还债还是回报股东 |
| §Q9 | 资产与负债经济分类、金额及占比 | 资产负债表最重要的风险和可选价值是什么 |
| §Q10 | 十年百分比利润表 | 收入到归母净利润之间哪些项目改变最大 |
| §Q11 | 贸易应收应付、合同负债、客户供应商集中度或平台分成 | 公司对客户、供应商和生态参与者有多大议价权 |
| §Q12 | 5-8 项结论摘要 | 数字支持或修正了哪些定性判断 |

表格默认采用“年度为行、指标为列”，便于十年阅读；指标超过6列时拆成两张
主题表。现有 profile 使用“指标为行、年度为列”时可以保留，但 HTML 必须
支持横向滚动，不能压缩到数字不可读。

## 8. 读者结论

每个 §Q 表后写一小段，避免复述所有数字。优先回答：

1. 十年中最大的结构变化是什么。
2. 最近三年与十年常态相比发生了什么。
3. 变化来自业务经营、资本配置还是会计列报。
4. 对未来利润、现金流、风险或估值的影响是什么。

正文不写“证据较强”“检查通过”“不能精确判断”“抽样一致”等研究过程。
缺口只在会改变读者理解时出现，例如“财报未单独披露腾讯云收入，因此无法
判断其利润率”。无实质影响的四舍五入、核对差异和搜索过程不写。

## 9. 完成检查

§Q1-§Q12 只有同时通过以下检查才可标完成：

1. **窗口覆盖：** 可取得10个可比完整财年时全部展示；短窗口说明原因。
2. **来源定位：** 每个报表原值能定位到年报、页码和口径；计算值能回到
   分子和分母。
3. **公式与分母：** 重算全部比率；平均余额、归母/合并口径、非正分母和
   CAGR 间隔正确。
4. **单位与币种：** 金额单位、币种、正负号和百分比一致，换算可复算。
5. **跨表勾稽：** 分部收入与集团收入、资产与负债加权益、利润表到现金流
   调节、现金期初到期末、股数与每股收益在披露容差内一致。
6. **可比性：** 重列、分部变化、会计政策和指标定义断点已经处理。
7. **行业适用性：** 不适用指标已替换；未披露指标未被估算成精确值。
8. **解释完整性：** 每个重要表都有“趋势→原因→影响”和证据等级。
9. **综合依赖：** §Q1-§Q11 完成后才能写 §Q12。

可以额外做独立抽样复核，但抽样不能替代上述全表检查。发现单行错误时只
阻断受影响的行和结论；系统性口径错误才使整个 Part 2 进入 `需人工`。
